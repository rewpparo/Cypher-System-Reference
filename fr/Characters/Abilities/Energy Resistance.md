Résistance aux énergies #Ability #ProtectionAbility #Mid #Core

Choisissez un type unique d'énergie avec laquelle vous avez de l'expérience
(comme la chaleur, le son, l'électricité, etc). Vous gagnez +5 d'armure contre
les dégâts de ce type d'énergie. Vous devez être familiers avec ce type
d'énergie ; par exemple si vous n'avez aucune expérience d'un certain type
d'énergie extradimensionnelle, vous ne pouvez pas vous en protéger. Vous pouvez
choisir cette aptitude plus d'une fois. Chaque vois que vous la choisissez,
choisissez un type d'énergie différent.

Facilitateur.
