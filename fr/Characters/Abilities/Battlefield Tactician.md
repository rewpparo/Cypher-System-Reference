Tacticien du Champ de Bataille (2+ points d'Intellect) #Ability #SensesAbility
#High #Core

Vous scrutez les alentours, et apprenez tous ce que le MJ pensera pertinent à
propos de l'attaque, la défense, les manœuvres et la manière de gérer les
dangers environnementaux à portée courte. Par exemple, vous pourriez remarquer
une tas de débris sur lequel vous pourriez monter pour un avantage en mêlée, un
coin protégé pour vous aider à vous protéger contre les attaques des ennemis, un
endroit moins glissant sur un lac gelé, ou un endroit où le gaz empoisonné est
moins épais qu'ailleurs. Si vous (ou quelqu'un que vous informez) se déplace
vers cet endroit, vous (ou il) gagne un tout sur les tâches liées à cette
position optimale (comme les jets d'attaques sur un terrain surélevé, les jets
de défense dans un coin abrité, les jets d'équilibre sur un lac gelé, ou les
défenses de puissance contre le nuage empoisonné). Au lieu d'apprendre une
position avantageuse, vous pourriez apprendre une position désavantageuse que
vous pourriez utiliser contre vos ennemis, comme les déplacer dans un coin peu
pratique qui gêne leurs attaques de mêlée, ou un endroit plus faible dans le lac
gelé qui se brisera s'ils se mettent là. Vous pouvez mettre de l’Effort pour
apprendre une position supplémentaire à portée, bonne ou mauvaise (un endroit
par niveau d'effort), améliorer la portée de cette aptitude (une distance courte
supplémentaire par niveau d'effort), ou les deux.

Facilitateur.
