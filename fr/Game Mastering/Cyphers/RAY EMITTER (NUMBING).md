RAY EMITTER (NUMBING) #Cypher #Fantastic #Core

Level: 1d6 + 2

Effect: Allows the user to project a ray of energy up to long range (very long
range if the cypher is level 6 or higher) that numbs one limb of the target,
making it useless for one minute. A small number of these devices (5%) induce
numbness that lasts for one hour.
